# Delivery

Send in the main chat: one short TLDR, one separate message per selected home with its actual photo, then a closing invitation. Do not collapse the homes into a table or reply thread.

TLDR: how many homes were checked, search area/budget, how many stood out, and the top pick's strongest evidence. A capped search is not the entire market.

Each numbered message contains:

- Address; asking price; beds, baths, living area.
- Comparison count, price basis, and reference price; Zestimate when available; explain the gap. With any asking-price fallback, label “Uses pending asking prices; Needs review.” State the split for mixed sets, such as “1 sale + 2 pending asks.” Show “Only one comparison” and “Zestimate unavailable” when applicable.
- A verified price cut when useful; any material concern must stay visible.
- The cover photo returned for that property ID, otherwise another returned photo. If none works, say “Photo unavailable.”

Illustrative wording only:

> **1. 123 Example Lane**<br>
> **$450,000** · 3 beds · 2 baths · 2,000 sq ft<br>
> Sold comparison: $520k. Zestimate: $500k.<br>
> Asking $50k below the lower reference. Price cut $25k on Sep 1.

When at least one property was sent, end: **“Want a closer look? Reply with a home's number.”**

Save the delivered number-to-ID mapping. A numbered reply uses that mapping, not a new search: show the supporting sold addresses, dates, prices, sizes, calculation, and relevant listing notes. No clickable Zillow listing links in this presentation.

Distinguish three outcomes: assessed with no qualifying homes, unassessed because price/comparison evidence was missing, and retrieval failure. For missing evidence, say “I couldn't assess these homes with the available price data,” not “nothing qualified.” Mixed coverage reports both counts. Without property messages, omit the numbered invitation; offer one relevant next step, such as the optional relaxed mode. Clearly count indicative leads separately from results based only on actual sales. Report “10 homes passed the relaxed screen,” not “10 confirmed underpriced homes.”
